I created this site as a place to keep my project documentation, tutorials, technical notes, and learning process in one searchable space.

{/* truncate */}

Most of my work moves between hardware, electronics, digital fabrication, embedded systems, software tools, and experiments that start as small questions. A normal portfolio only shows the finished result, but that misses the useful part: the decisions, mistakes, fixes, files, and references that helped the project move forward.

This blog is where I will write shorter updates and reflections. The full build logs and project files will live in the Projects section, while reusable tutorials and notes will live in Docs.

The goal is simple: make my work easier to revisit, easier to share, and easier for someone else to learn from.
