# Docs and Tutorials

This section is for the notes, tutorials, and technical references I create while learning, building, and documenting my work.

The project write-ups live separately in the **Projects** section. Here, I want to keep material that is more reusable: guides, workflows, setup notes, design references, troubleshooting steps, and tutorials that can be followed independently.

## What You'll Find Here

### Tutorials

Step-by-step guides for tools, processes, electronics, fabrication, programming, and other topics I work with.

### Technical Notes

Short references, explanations, commands, design decisions, and lessons learned that are useful beyond one specific project.

### Project-Related Guides

Some tutorials may come from projects I have built. In those cases, the full project documentation stays in the Projects section, while the reusable tutorial or method will be kept here.

### Learning References

Organized notes from experiments, classes, workshops, debugging sessions, and things I want to remember or share.

## How to Navigate

- Use **Docs** for tutorials, references, and reusable learning material.
- Use **Projects** for complete project documentation, build logs, files, and outcomes.
- Use **Blog** for updates, reflections, and posts that do not need to be structured as documentation.

## About This Section

This is a growing knowledge base. Some pages may be polished tutorials, while others may be practical notes that I update as I learn more.
